## Featured project

### [EDIFlow Canada — X12 850 Integration & Monitoring](https://github.com/Grishmakhatra932/ediflow-canada)

A personal project demonstrating an ANSI X12 850 purchase-order workflow.

- Parses and validates X12 850 documents, including ISA, BEG, N1, and PO1 segments.
- Checks buyer/supplier, quantity, price, duplicate control numbers, and duplicate purchase orders.
- Simulates ERP integration with retry and permanent-failure handling.
- Records transaction statuses in PostgreSQL.
- Includes API-key authentication, logging, API/integration tests, Docker Compose, Prometheus, and Grafana.

**Project stack:** `Python` · `FastAPI` · `PostgreSQL` · `Docker` · `Prometheus` · `Grafana`
