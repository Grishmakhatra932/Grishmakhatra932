## Featured project

### [EDIFlow Canada — X12 850 Integration & Monitoring](https://github.com/Grishmakhatra932/ediflow-canada)

A personal project that demonstrates an ANSI X12 850 purchase-order workflow.

- Parses and validates X12 850 documents, including ISA, BEG, N1, and PO1 segments.

- Records transaction results in PostgreSQL.
- Built with Python, FastAPI, PostgreSQL, Docker, Prometheus, and Grafana.
