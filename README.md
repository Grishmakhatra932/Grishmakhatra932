## Featured project

### [EDIFlow Canada — X12 850 Integration and Monitoring](https://github.com/Grishmakhatra932/ediflow-canada)

A personal project demonstrating an ANSI X12 850 purchase-order workflow.

- Parses and validates X12 850 documents, including ISA, BEG, N1, and PO1 segments.
- Checks required purchase-order data and detects duplicate control numbers and orders.
- Simulates ERP integration with retry and failure handling.
- Records transaction results and processing status in PostgreSQL.
- Includes API-key authentication, Docker containerization, Prometheus metrics, and Grafana dashboards.
- Built with **Python, FastAPI, PostgreSQL, Docker, Prometheus, and Grafana**.
